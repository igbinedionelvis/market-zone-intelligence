# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for market-zone-intelligence.

## Format

Each ADR follows a consistent structure:

- **Status** — proposed, accepted, deprecated, superseded
- **Context** — the issue or question
- **Decision** — what was decided
- **Consequences** — trade-offs and follow-ups

## Index

| ADR | Title | Status |
|-----|-------|--------|

## Creating a New ADR

1. Copy the structure from an existing ADR.
2. Number sequentially (`ADR-002-...`).
3. Set status to `Proposed` until reviewed.
4. Link from this index and relevant docs (`DOMAIN_MODEL.md`, `ARCHITECTURE.md`).
